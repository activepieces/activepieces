# Vibe Prospecting

B2B company and contact intelligence for prospecting workflows.

## Authentication

Create an API key in the Explorium admin console:

1. Sign up or sign in at https://www.explorium.ai/sign-up/
2. Open https://admin.explorium.ai
3. Generate an API key

Docs: https://developers.explorium.ai/reference/setup/getting_your_api_key

The piece sends the key in the `api_key` request header to `https://api.explorium.ai`.
