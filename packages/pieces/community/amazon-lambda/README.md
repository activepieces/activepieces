# pieces-amazon-lambda

Invoke AWS Lambda functions, read their configuration, call the Lambda API with a signed request, and watch for new functions.

## Building

Run `turbo run build --filter=@activepieces/piece-amazon-lambda` to build the library.

## Logo

`logoUrl` points at `https://cdn.activepieces.com/pieces/amazon-lambda.png`. That file is not on the CDN yet.

`amazon-lambda-logo.png` in this folder is a 500×500 PNG of the AWS Lambda mark. Please upload it to that URL when merging.
