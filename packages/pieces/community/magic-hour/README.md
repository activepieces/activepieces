# piece-magic-hour

Activepieces piece for [Magic Hour](https://magichour.ai): generate videos and images from text or images with Sora 2, Veo 3.1, Kling 3.0, Seedance, MiniMax, WAN 2.2, LTX 2.3, GPT-image, Nano Banana Pro and more through one API key.

API docs: https://docs.magichour.ai

## Building

Run `bun run build` inside this directory.
