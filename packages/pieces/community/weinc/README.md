# WeInc

Activepieces piece for [WeInc](https://we.inc), an AI website builder with white-label client accounts.

Authenticate with an organization API key (starts with `wk_`). The piece calls the WeInc REST API at `https://my.we.inc/api/v1`.

Actions: Create Project, Get Project, List Projects, Update Project, Get Preview URLs, Create Client, List Clients, Custom API Call.
Trigger: New Project (polling).
