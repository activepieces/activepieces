# Blog Automation

[Blog Automation](https://blog-automation.com) writes SEO blog articles with AI and publishes them to WordPress, Shopify, Webflow, Ghost and 30+ other platforms.

- Actions: create idea, write article (AI), get job, get article status, add to calendar, publish article, token balance, custom API call
- Triggers (instant webhooks, HMAC-signed): article ready for review, article published, publishing failed
- Auth: API key from Blog Automation → Entwickler / API (`ba_live_…`)
- API reference: https://blog-automation.com/developers/
