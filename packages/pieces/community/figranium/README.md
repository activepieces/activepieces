# Figranium Activepieces Piece

Activepieces piece for integrating Figranium browser automation into workflows.

## Piece contents

### Auth
- Custom Auth with `baseUrl` and `apiKey`.

### Actions
- Execute Task
- List Tasks
- List Executions
- List Schedules
- Get Schedule Status
- Get Scheduler Status
- Set Schedule
- Delete Schedule
- Describe Schedule
- Custom API Call

## Wiring
- Build via `npx turbo run build --filter=@activepieces/piece-figranium`.
