 Embedding lets you make Activepieces automation capabilities available inside your own product or website. 

The Embed Onboarding page helps platform admins configure the platform-level settings required before embedding Activepieces into an application. 

### Set up Embedding 

The onboarding process has four steps:

1. **Enter the embed URL :** Enter the domain where you want to embed Activepieces. Use a subdomain that your organization controls, for example: flows.acme.com Click Save domain to continue.
2. **Verify the DNS records:** Configure the provided DNS records for your domain and complete the verification process. This connects the domain you entered to your Activepieces embedded environment.
3. **Add allowed domains:** Add the domains that are allowed to host your embedded Activepieces experience. This lets you control which applications or websites can use the embedded experience.
4. **Add signing keys**: Add the signing keys required for your embedded setup. These keys are used as part of the authentication process between your application and Activepieces.
