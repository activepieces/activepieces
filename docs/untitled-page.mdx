# Deploy Activepieces on Hostinger

Hostinger provides a one-click way to deploy Activepieces on a VPS. The Activepieces application comes preconfigured, so you don't need to manually set up Docker or install Activepieces yourself.

## Prerequisites

Before getting started, you will need:

- A Hostinger account
- A Hostinger VPS plan

## Deploy Activepieces

![Vps Plan Activepieces](/images/vps-plan-activepieces.png "Vps Plan Activepieces")

1. Go to the [Activepieces application page on Hostinger](https://www.hostinger.com/applications/activepieces).
2. Click **Choose plan** and select the VPS plan that fits your needs.Hostinger offers multiple VPS configurations with different amounts of CPU, memory, storage, and bandwidth.
3. After selecting a plan, you will be taken to the billing page. 
4. Click on **Continue** and you will be directed to sign in to your Hostinger account or create a new account.
4. Complete the VPS setup and select Activepieces as your application.
5. Choose your server location and finish creating the VPS.

Hostinger will automatically deploy the preconfigured Activepieces application on your VPS.

Once the deployment is complete, open your Activepieces instance and create your account to start building automations.

## Managing your deployment

You can manage your Activepieces deployment from Hostinger's VPS dashboard.

Hostinger provides tools for managing the Docker deployment, including:

- Docker container management
- Container logs
- One-click updates
- Automatic weekly backups

For more information, see the [Activepieces page on Hostinger](https://www.hostinger.com/applications/activepieces).
