## What has changed?

#### ConvertKit 0.5.0: Link Clicked and Product Purchased run the flow once per event

From ConvertKit 0.5.0, **Link Clicked** and **Product Purchased** run the flow once per event, with the subscriber as the trigger output. Before, each event also started a second run whose trigger output was only the watched link URL or the product ID.

#### What you need to do

If a flow on Link Clicked or Product Purchased handled that second run on purpose, read the link URL or product ID from the trigger's settings instead.
