## What has changed?

#### Captain Data 0.3.0: the v3 actions are retired, and the piece now uses Captain Data's v1 API

Captain Data shut down its v3 API on January 9, 2026. **Launch a workflow** and **Get job results** are now marked (Deprecated), are shown only in the flow builder, and fail with a message that explains the shutdown. Their Workflow and Job dropdowns are now plain text fields. AI agents and MCP clients get the new people and company tools instead (Find Person, Search People, Enrich Person, Find Company, Search Companies, Enrich Company, Find Company Employees and others).

The connection's **Project ID** is no longer required or used. **Custom API Call** now goes to `https://api.captaindata.com/v1` with the `X-API-Key` header.

#### What you need to do

- Replace steps that use Launch a workflow or Get job results with the new people and company actions.
- Custom API Call steps that called v3 paths: update them to the v1 endpoints.
