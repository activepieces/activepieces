## Flow or agent?

Both can be built by describing what you want. The difference is **when the path gets decided**.

|  | Flow | Agent |
|---|---|---|
| **The path is decided** | Once, when you build it | Every run, by the agent |
| **Same input twice** | Same steps, same order | May take a different route |
| **Best when** | You know the procedure | The work varies case by case |
| **You steer it by** | Changing the steps | Changing instructions and tools |

A flow is predictable, which is what you want for anything that must happen the same way every time. An agent handles the cases you cannot enumerate in advance. Agents can call flows as tools, so the parts that need to be exact stay exact.
