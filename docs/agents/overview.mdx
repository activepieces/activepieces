## Flow or agent?

|  | Flow | Agent |
|---|---|---|
| **Steps** | You draw them | It decides them |
| **Best when** | The process is known | The work varies |
| **Same input twice** | Same path | May take a different route |
| **You steer it by** | Editing steps | Instructions and tools |

Agents can call flows as tools, so the reliable parts stay a flow.
