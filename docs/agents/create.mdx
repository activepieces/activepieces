Every route lands in the same editor, and nothing is locked in. You need an [AI provider connected](/admin-guide/guides/setup-ai-providers) before any of them will work.

## Set it up

The **Configure** tab holds everything that changes what the agent does.

| Setting | What it's for |
|---|---|
| **Instructions** | The job it owns, how to decide, and when to stop. This is the agent. |
| **[Tools](/agents/tools)** | What it can reach. Apps, your own flows, MCP servers, and [knowledge](/agents/knowledge). Without tools it can only talk. |
| **Model** | Which model answers, and whose key pays for it. |
| **Output fields** | Return named fields instead of prose, so a [flow can use the result](/agents/in-flows). |
| **Max steps** | The budget for one run. A stuck agent stops instead of looping. |

The **Settings** tab is name, description, and how it looks in the list.

## Try it

The editor has a conversation panel beside the configuration. Talk to the agent there, watch which tools it reaches for, and adjust the instructions until it behaves. Changes take effect as soon as you save.

<Tip>
Brief it like a capable new colleague. Say the goal and the edges, not every keystroke. The two people forget most: what "done" looks like, and which calls it should hand back to a human.
</Tip>
