Each comes with instructions and tools already chosen. Or pick **Start blank**.

## Write the instructions

Name and description are for your team. **Instructions** are what the agent actually runs on, and cover three things:

| | |
|---|---|
| **The job** | What outcome it owns |
| **How to behave** | Tone, what to assume, when to ask |
| **When to stop** | What "done" looks like, and what it must never do |

<Tip>
Brief it like a capable new colleague. Say the goal and the edges, not every keystroke.
</Tip>

## Then give it tools

An agent with no tools can only talk. [Add tools](/agents/tools) so it can act.

## Publish

Agents have a **draft** and a **published** version, like flows. Tuning the draft never disturbs what's running.
