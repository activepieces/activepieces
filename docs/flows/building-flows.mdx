## Trigger

This is the flow's starting point. It determines the frequency of execution. There are various types of triggers available, such as Schedule Trigger, Webhook Trigger, or Event Trigger based on specific service.

<video src="https://cdn.activepieces.com/videos/docs/triggers.mp4" controls />

## Action

Actions come after the trigger and control what occurs when the flow is activated, like running code or communicating with other services.
