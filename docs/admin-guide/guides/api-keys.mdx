API keys let your scripts and services call the [Activepieces API](/endpoints/overview) for the whole platform, without signing in as a person.

### **Create an API Key**

**Step 1**: Go to **Platform Admin → Developers → API Keys**.

**Step 2**: Click **New API Key**.

**Step 3**: Enter a **Name** and click **Create**.

**Step 4**: Copy the key from the dialog. It is shown only once, and you can't view it again after you close the dialog.

### **View API Keys**

For each key, the table shows:

- **Name**: The name you gave the key.
- **Created**: When the key was created.
- **Last used**: When the key last called the API, or **Never used**.

### **Revoke an API Key**

Open the menu of the key, click **Revoke API Key**, then click **Revoke**. Anything still using the key stops working right away.

### **Good practice**

- Give each service its own key, so you can revoke one without breaking the others.
- Keep keys in a secret store, never in code.

AI assistants connected over [MCP](/admin-guide/guides/mcp-server) can list API keys, and revoke them when changing platform settings is switched on. They can't create keys, because a new key is shown only once.
