The **Usage** page shows platform admins how the platform consumes the resources of its plan. It is available on Cloud and in the Enterprise edition.

The figures can be a few minutes behind the latest activity.

### Plan usage

At the top of the page, a card for each resource shows how much the platform uses and the limit of the plan:

- **Credits:** The credits used in the current billing period.
- **Users:** The active users of the platform, plus the invitations that are not accepted yet.
- **Active Flows** and **Team Projects:** Shown only when your plan limits them.

A resource with no limit in your plan shows **Unlimited**.

### Credits Usage by Project

The table breaks the credits down by project, so you can see where the usage comes from. For each project, you see:

- **AI Usage:** Credits used by AI steps and chat.
- **Runs Usage:** All other credits, mainly flow runs. Each run of a published flow uses one credit, whether it succeeds or fails. A test run in the builder uses none.
- **Total:** All the credits the project used.

The table shows the last 30 days. Use the date picker to choose a different date range. Click a project name to open that project.

To see what each action costs in credits, open **Usage breakdown** on the **Billing** page.
