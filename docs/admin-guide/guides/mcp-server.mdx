The **MCP Server** page controls what AI clients, such as Claude, ChatGPT or Cursor, can do when they connect to Activepieces over [MCP](/mcp/overview).

Go to **Platform Admin → Developers → MCP Server**.

### **Tools**

The tools are grouped by what they can do:

- **View**: Read flows, runs, tables, connections and pieces. Always on.
- **Edit flows**: Create, rename and duplicate flows, and edit drafts.
- **Publish and run**: Publish, test and run flows and actions, and change tables.
- **Delete**: Permanently delete flows, tables, fields and records.

Switch a group or a single tool off, and it's off for every project and every connected client. A project admin can switch off more tools in their own project, but can't switch back on a tool the platform switched off.

### **Activity**

**Activity** lists the piece actions that connected clients ran, newest first.

### **Who can connect**

Each person connects their own AI client and signs in with their own account. A client can never do more than the person who connected it.
