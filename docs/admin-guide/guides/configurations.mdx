**Configurations** holds settings that apply to every project on a self-hosted platform. It is not shown on Activepieces Cloud.

Go to **Platform Admin → Account → Configurations**.

### **Telemetry**

Telemetry helps us improve Activepieces. We never receive what your flows do, the data they process, or anything inside your connections and API keys.

- **Product analytics**: Shares usage events, so we can see which features are used and fix what breaks. Click **See the events we track** for the full list.
- **Deployment setup**: Sends a snapshot of your Workers and Health pages, without IPs or hostnames, so we can answer your support questions faster.

For more, see [Telemetry](/install/configure-operate/telemetry).
